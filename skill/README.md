# pawapay-merchant-api-v2 — Claude skill

This folder is a **Claude skill** — a self-contained bundle of reference docs + scripts that you load into Claude so it can write production-grade pawaPay integrations without you having to dig through API docs.

This is the same skill that was used to build the WooCommerce plugin in this repo in roughly six prompts. You can use it to build whatever you want.

🎥 **Demo**: [Loom walkthrough](https://www.loom.com/share/af99d1a8a13048a89220d21f1e001226)

## What's in here

| Path | What it is |
| --- | --- |
| `SKILL.md` | The top-level skill instructions Claude reads first — covers the async state machine, signing, sandbox setup, and decision tree pointing to the right reference |
| `references/` | Deep-dive endpoint docs (deposits, payouts, refunds, remittances, payment page, statements, toolkit, callbacks, errors, testing, providers, auth) |
| `scripts/` | Reference implementations of RFC 9421 request signing (Node + Python) and callback signature verification (Python) |

## How to use it

The simplest path is **Claude Code** (the CLI). Drop the skill into your project or user skills directory and it becomes invokable inside any Claude Code session.

### Option 1 — project-local (recommended for hackathon use)

From inside the project you're working on:

```bash
mkdir -p .claude/skills
cp -r /path/to/pawapay-builders/skill .claude/skills/pawapay-merchant-api-v2
```

Then start Claude Code in that project. The skill auto-activates whenever you mention pawaPay, mobile money, MMO, MTN MoMo, M-Pesa, Wave, deposits/payouts, etc. — see the `description` field in `SKILL.md` for triggers.

### Option 2 — user-wide

If you want the skill available across every project on your machine:

```bash
mkdir -p ~/.claude/skills
cp -r /path/to/pawapay-builders/skill ~/.claude/skills/pawapay-merchant-api-v2
```

### Option 3 — Claude.ai (web)

Open Claude.ai in Code mode, go to skills, and upload this folder. Refer to the [Loom walkthrough](https://www.loom.com/share/af99d1a8a13048a89220d21f1e001226) for the flow.

## What to ask Claude once the skill is loaded

The skill is at its best when you give Claude a concrete build task. Examples:

- *"Build a Next.js API route that accepts a phone number and amount, validates the number via `predict-provider`, then initiates a sandbox deposit. Persist the depositId and poll for status."*
- *"Add a Wave redirect flow to my existing pawaPay deposit handler."*
- *"Write a Python callback handler that verifies pawaPay's RFC 9421 signature and is idempotent on retry."*
- *"Walk me through what needs to change in my code to handle the `ENQUEUED` state on payouts."*

Claude will read the right reference file(s) before generating code, and use the scripts in `scripts/` as the source of truth for signing.

## Things to know

- The skill is targeted at the **Merchant API v2** — not v1. Don't be surprised if it refuses to write v1 calls.
- The skill expects you to have a sandbox API token (see [`../docs/getting-started.md`](../docs/getting-started.md) for how to get one for the hackathon).
- Amounts are always **strings** (never floats). The skill enforces this — let it.
- Every transaction needs a **UUIDv4 ID generated by you** before the API call, for idempotency. The skill drills this in.
